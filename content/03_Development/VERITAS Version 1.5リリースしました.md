# VERITAS Version 1.5リリースしました

VERITAS Version 1.5 をリリースしました。

今回のアップデートでは、VERITAS のシンプルな再生体験はそのままに、プレイリスト機能、外部プレイリスト取り込み、再生時の快適さ、アクセス許可まわりの使い勝手をまとめて強化しました。  
ローカル音楽ライブラリをより実用的に扱いやすくする、節目のアップデートです。

## ダウンロード

- 製品版: [https://veritas-software.stores.jp/items/69ffe589717fd97892a1406a](https://veritas-software.stores.jp/items/69ffe589717fd97892a1406a)
- Trial版: [https://veritas-software.stores.jp/items/6a032f8b9bd874505f404cc6](https://veritas-software.stores.jp/items/6a032f8b9bd874505f404cc6)

## 追加された機能

- プレイリストをアプリ内で作成・保存・編集できるようになりました
- 保存したプレイリストをサイドバーからすぐ開けるようになりました
- Music.app / iTunes のプレイリストを VERITAS に取り込めるようになりました
- `m3u` / `m3u8` / `PLS` / `XSPF` など、一般的なプレイリストファイルの読み込みに対応しました
- プレイリスト取り込み前に、内容や読み込めない曲を確認できるようになりました
- 単体の音楽ファイルを開いたり、ドラッグ＆ドロップしてすぐ再生しやすくなりました
- キーボードショートカットを強化し、検索や曲送りをすばやく操作できるようになりました
- Smart Preload により、再生開始や曲送りがより軽快になりました
- プレイリスト再生でも、次の曲をよりスムーズに再生しやすくなりました
- 一度許可したフォルダへのアクセスを記憶し、毎回の許可操作を減らしました
- ヘルプ画面、ショートカット一覧、診断情報の書き出しに対応しました

## 今回のアップデートについて

VERITAS 1.5 では、フォルダを開いてすぐ聴けるわかりやすさを保ちながら、プレイリストをより自然に使えるよう改善しました。  
アプリ内でプレイリストを作成して保存できるだけでなく、保存済みのプレイリストをサイドバーからすぐ開けるため、日常的な再生操作がよりスムーズになっています。

また、Music.app / iTunes からの取り込みや、`m3u` など一般的なプレイリスト形式にも対応したことで、これまで使っていた環境から VERITAS への移行もしやすくなりました。  
取り込み前には内容を確認できるため、どの曲が読み込まれるか、どの曲が未解決なのかを把握しながら安心して取り込めます。

再生まわりでは、単体ファイルのオープン、ドラッグ＆ドロップ、キーボードショートカット、Smart Preload などを見直し、再生開始や曲送り時の軽快さも向上しました。  
さらに、一度許可したフォルダを記憶する仕組みや、ヘルプ画面・ショートカット一覧も加わり、初めて使う方にも扱いやすい構成になっています。

## 今後について

今後は App Store 公開に向けた改修も進めていく予定です。  
配布方式については、App 内課金によって機能を解放する App-in Purchase 方式を採用し、課金後は現在の製品版と同等の機能が使える構成を目指しています。

これにより、より多くの方に導入していただきやすい形で VERITAS を届けられるようにし、最終的にはグローバルリリースを目指して開発を進めていきます。

# VERITAS Version 1.5 is now available

VERITAS Version 1.5 is now available.

This update keeps the simple playback experience of VERITAS intact while significantly improving playlist features, external playlist import, playback responsiveness, and file access usability.  
It marks an important step toward making local music libraries easier and more practical to manage in everyday use.

## Download

- Full Version: [https://veritas-software.stores.jp/items/69ffe589717fd97892a1406a](https://veritas-software.stores.jp/items/69ffe589717fd97892a1406a)
- Trial Version: [https://veritas-software.stores.jp/items/6a032f8b9bd874505f404cc6](https://veritas-software.stores.jp/items/6a032f8b9bd874505f404cc6)

## What’s New

- You can now create, save, and edit playlists directly inside the app
- Saved playlists are now available from the sidebar for quicker access
- You can now import playlists from Music.app / iTunes into VERITAS
- Support has been added for common playlist formats including `m3u`, `m3u8`, `PLS`, and `XSPF`
- You can now review playlist contents and detect unresolved tracks before importing
- Opening and playing single audio files is now smoother with both Open and drag-and-drop
- Keyboard shortcuts have been improved for faster search and track navigation
- Smart Preload now makes playback start and track changes feel faster and more responsive
- Playlist playback now benefits from smoother next-track preparation
- VERITAS now remembers previously granted folder access, reducing repeated permission prompts
- A Help window, shortcut guide, and diagnostic export have been added

## About This Update

With VERITAS 1.5, we focused on making playlists feel like a more natural part of the app while preserving the simplicity of opening a folder and playing music right away.  
You can now create and save playlists inside VERITAS, and open saved playlists directly from the sidebar for a smoother everyday listening experience.

Support for Music.app / iTunes import and standard playlist formats such as `m3u` also makes it easier to move from an existing music setup into VERITAS.  
Before importing, you can review what will be brought in, including which tracks are resolved and which items may still need attention.

Playback usability has also been improved through better single-file opening, drag-and-drop behavior, keyboard shortcuts, and Smart Preload.  
In addition, remembered folder permissions, a Help window, and a shortcut reference make VERITAS easier to use, especially for first-time users.

## Looking Ahead

We are also preparing VERITAS for a future App Store release.  
As part of that work, we plan to move to an in-app purchase model, where unlocking the paid version will enable features equivalent to the current full version.

Our goal is to make VERITAS easier to access for more users and continue improving it toward a broader global release.

## Summary

VERITAS 1.5 is an update that keeps the app fast and simple while making it much more practical for playlist management and library migration.

We will continue refining VERITAS as a music player built for comfortable local library playback.
